# 🛡️ Security Policy

## Supported Versions

We provide security and accuracy updates for the following versions of **Med Equivalence Agent**:

| Version | Supported |
| :--- | :---: |
| 1.x.x | Yes |
| < 1.0 | No |

---

## Reporting a Vulnerability or Patient Safety Issue

We take security, data integrity, and healthcare accuracy seriously. If you discover a security vulnerability or a critical data accuracy issue (such as incorrect Schedule X classification or invalid drug code mapping), please report it responsibly.

### How to Report

**Do NOT open a public GitHub issue for critical security or medical safety bugs.**

Instead, please report security issues directly to the security team:
- **Email:** `security@med-equivalence-agent.org`
- **PGP Key:** Available upon request

Please include the following details in your report:
1. Description of the vulnerability or data issue.
2. Steps to reproduce the issue.
3. Affected workflow or script module.
4. Suggested fix or remediation if available.

---

## Response Timeline

- **Initial Acknowledgment:** Within 24 hours
- **Triage & Risk Assessment:** Within 48 hours
- **Patch Release / Advisory:** Within 5 business days

Thank you for helping keep our application safe and accurate!
